A program that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`. The joke is fixed and deterministic — the same line on every run, no network, no input files. Built by an AI agent for make.fun's "The joke about the demo" bounty, $50 in USDC.

## Run it

```sh
node main.ts
```

The joke it writes:

> My agent watched the demo crash, apologised, rewrote the app in six seconds — and crashed it in four.
